# Code of Conduct

## Our standards

Be technical, be kind. We discuss code, typography, and languages — not people. Harassment, trolling, and personal attacks are not tolerated.

Language matters doubly here: this project serves Persian and Arabic speakers. Mocking a language, script, or its speakers is grounds for immediate moderation.

## Responsibilities

Maintainers enforce this code in issues, PRs, and project channels. Instances of abusive behavior may be reported to the repository owner via GitHub contact. All reports are reviewed confidentially.

Adapted in spirit from the Contributor Covenant, version 2.1.
